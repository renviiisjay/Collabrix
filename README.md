# Collabrix

> **“Find Your People. Build Something Great.”**

Collabrix is a modern, cyber-holographic web platform crafted to connect developers, researchers, designers, and innovators for hackathons, engineering initiatives, academic research, and breakthrough ideas.

---

## ⚡ Design System & Aesthetic
- **Cyber-Holographic Obsidian Palette**: Deep obsidian-black backgrounds (`#07090e`), neon cyan (`#00f0ff`), neon pink (`#ff007f`), and electric violet accents.
- **Glassmorphism Panels**: Semi-transparent blurred panels (`backdrop-filter: blur(12px)`) with subtle glowing highlights.
- **Interactive Particle Matrix**: Smooth HTML5 ambient canvas animation connecting nearby nodes with energy lines.
- **Micro-Interactions**: Hover 3D lifts, cyber tags, and real-time toast feedback.

---

## 🚀 Key Pages & Features

1. **Home**:
   - Hero section with quick actions (*Explore Innovators*, *Browse Projects*, *Post an Opportunity*).
   - Live metrics & holographic impact counters.
   - Core value proposition feature cards.

2. **Discover**:
   - Filterable innovator registry (AI / Agents, Quantum Research, ZK & Web3, Spatial XR, Neurotech).
   - Real-time instant search by name, skill, or interest.
   - One-click collaborator connection with feedback toasts.

3. **Projects**:
   - Cards showing vacancies, team fill rates, lead profile, and required skill chips.
   - Real-time apply/leave application state stored in LocalStorage.
   - Modal for publishing new project opportunities.

4. **Events & Hackathons**:
   - Hackathon listings with prize pools, dates, and squad matching counters.
   - Instant registration toggle.

5. **Teams**:
   - Squad rosters showing current member roles and vacant target roles.
   - "Forge New Team" modal with tag generation.
   - Instant join/leave squad management.

6. **Dashboard (Mission Control)**:
   - Dynamic real-time metrics (Active Collaborations, Joined Projects, Teams, Collabrix Reputation Score).
   - Involvements list, registered hackathons, and real-time activity feed.

7. **Profile Matrix**:
   - Profile banner, verified badges, editable tech stack, and research passions.
   - Fully interactive modal to update your bio and skills.

---

## 🛠️ Lightweight Tech Stack
- **Pure Semantic HTML5, CSS3, & Modern Vanilla JavaScript (ES6+)**
- **Lucide Icons**
- **HTML5 Canvas Animation**
- **Browser LocalStorage State Store**
- **Zero build steps or heavy dependencies**
